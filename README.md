# 💰 Expense Tracker Web API

Expense Tracker is an **ASP.NET Core Web API** project that allows users to securely register, log in, and manage their personal expenses.

The project demonstrates REST API development using **ASP.NET Core, Entity Framework Core, SQL Server, JWT Authentication, LINQ, Dependency Injection, and CRUD operations**.

---

## 🚀 Features

- User Registration
- User Login
- View All Expenses
- View Expense by ID
- Update Expense
- Delete Expense
- Store data in SQL Server
- Entity Framework Core
- Code First Approach
- Database Migrations
- Password Hashing
- Dependency Injection
- Async/Await
- LINQ Queries
- RESTful API Architecture
- Proper HTTP Status Codes
